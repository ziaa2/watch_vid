# Airdrop Radar

Tracker airdrop pribadi: paste pesan grup Telegram, task, deadline, dan link terpilah otomatis. Data tersimpan di browser (tanpa server).

## Deploy ke GitHub Pages
1. Buat repo baru, upload semua file di folder ini ke root repo.
2. Settings > Pages > Source: branch `main`, folder `/ (root)`.
3. Buka `https://<username>.github.io/<nama-repo>/`, lalu di HP pilih "Tambahkan ke layar utama".

Data dummy contoh ada di `seed()` di `index.html`; hapus isinya kalau mau mulai kosong.
